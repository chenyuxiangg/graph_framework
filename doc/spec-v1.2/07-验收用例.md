> **fixture 落点（M5 权威口径）**：验收资产统一落 `tests/fixtures/graphs/**`（architecture §2.2；仓库**无** `examples/`）。上表 `<case>` 指各用例的 fixture 目录（如 `harness_ac08/`）；AC-01 的完整 CLI 资产（agent / prompt / python 回调 / fake 脚本）已由 REV-032 交付（`tests/fixtures/graphs/customer_ticket/**`），本表即当前落点。

**LLM 两种模式**：`--fake-llm` 用脚本化 provider（CI 默认，无网络）；`--real` 用 DeepSeek（`DEEPSEEK_API_KEY`，仅在 AC-08 手动执行）。**`--fake-llm` 语义（REV-028）**：裸 flag 使用 CLI **内置默认脚本**（一段文本 + 一次 `tool_calls`；`calls` 用尽后按 spec 重复最后一项），**内容不保证确定**；确定性验收（AC-01/AC-08）必须用 `--fake-llm=<script>` 指定脚本。

## AC-10 暂停/恢复/取消

- **暂停**：run 含 2 个串行 Python 节点（各 0.3s），第 1 个执行中发 Pause → 第 2 个不派发；等待 1s 无新 Running；Resume 后完成。

- **幂等**：重复 Pause/Resume/Cancel 不改变结果、不重复 `RunFinished`。
