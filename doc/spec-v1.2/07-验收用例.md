- **前置**：`--fake-llm`，脚本让 `input_parser` 返回 `{"parsed_query":"退款政策","user_id":"u1"}`、`kb_search` 返回 `{"kb_result":{"hits":1}}`、`answer_writer` 返回 `{"answer":"可以退款","need_human":false}`。
- **步骤**：
  ```bash
  zgraph validate tests/fixtures/graphs/customer_ticket.json
  zgraph run tests/fixtures/graphs/customer_ticket.json \
    --inputs '{"input_parser":{"user_message":"我要退款"}}' \
    --assets-dir tests/fixtures/graphs/customer_ticket \
    --python-path python \
    --python-path tests/fixtures/graphs/customer_ticket/py \
    --fake-llm=tests/fixtures/graphs/customer_ticket/fake_llm.json \
  ```

## AC-06 超时杀进程组不挂死

- **前置**：`nodes/slow.py` 执行 `time.sleep(30)`（可再派生孙进程以验证进程组）；节点 `timeout_ms=1000`。
- **步骤**：`zgraph run ... --json`，计时；用 `pgrep -g <pgid>`/`kill(pid,0)` 检查残留。
- **判定（v2/D1，M3 真 worker 口径）**：
  - **进程组被 kill**：`cancel` 帧 → 2s → `SIGTERM` → 1s → `SIGKILL`（对进程组，含孙进程）；
  - **无残留子进程**：reap 后进程组内无存活 PID（AC 断言）；
  - **run 在 5s 内失败**：不等待 30s；实例 `TimedOut`、run `Failed`（`NODE_TIMEOUT`），退出码非 0；
  - trace 有 `NodeTimedOut`；`killed_workers ≥ 1`；`NodeAbandoned` **不产生**、`abandoned_tasks` **恒 0**；
  - 进程正常退出（`shutdown_timeout` 生效）。

## AC-10 暂停/恢复/取消

- **暂停**：run 含 2 个串行 Python 节点（各 0.3s），第 1 个执行中发 Pause → 第 2 个不派发；等待 1s 无新 Running；Resume 后完成。

- **幂等**：重复 Pause/Resume/Cancel 不改变结果、不重复 `RunFinished`。
