## 0.1 读法与约定

- **MUST / MUST NOT / SHOULD / MAY**：分别表示强制、禁止、建议、可选。实现与测试以此判定合规。
- 本规格中所有 Rust 片段是**契约级伪代码**：字段名、枚举、语义是强制的；所有权/生命周期写法是建议（实现可按第 03 分册的所有权模型调整），但**不得改变语义**。
- 所有时间戳为 UTC RFC3339；时间量单位为毫秒（`_ms` 后缀）。
- `Value` = `serde_json::Value`。
- **DSL schema 版本保持 `"version": "1.0"` 不变**（新增字段均为可选/保留字，向后兼容）；本文档自身版本为 v1.2。
- **语义收紧说明**：符号命名从 v1.1 的短名收紧为全限定 `module.function`（02 §2.5）；这是语义收紧而非字段变更，v1 不兼容旧短名。

## 0.2 ID 与类型别名

| 别名 | 底层 | 生成规则 | 说明 |
|---|---|---|---|
| `NodeId` | `String` | DSL 中声明 | 图内唯一 |
| `SubgraphId` | `String` | DSL 中声明 | 子图内唯一 |
| `PortName` | `String` | DSL 中声明 | 节点内唯一 |
| `EdgeIndex` | `usize` | 编译期按 `edges` 数组顺序 | 边的稳定标识 |
| `RunId` | `String` | UUIDv7 | 全局唯一、时间有序 |
| `InstanceId` | `String` | UUIDv7 | 全局唯一；实例创建时生成 |
| `Attempt` | `u32` | 从 0 开始 | 同节点重建实例时 +1（仅自环/重试） |
| `GraphHash` | `String` | `blake3` 规范化 JSON，取前 16 hex | run 与图定义绑定 |

> 实例唯一性由 `InstanceId` 保证；`(NodeId, Attempt)` 仅用于**定位同一节点的当前实例**（v1 同一节点同时最多一个活跃实例，见 01 分册 §1.4）。

## 0.3 枚举（权威定义）

```rust
/// DSL 节点类型
pub enum NodeType { Start, End, PythonNode, AgentCall, Subgraph }   // Subgraph: v1 运行时不支持

/// 实例状态（v1 全部可产生的状态）
pub enum InstanceStatus {
    Pending,    // 已创建，等待输入
    Ready,      // 输入就绪，等待调度
    Running,    // 已派发执行
    Completed,  // 成功（终态）
    Crashed,    // 失败（终态）
    TimedOut,   // 超时（终态，stop-waiting 语义）
    Cancelled,  // 被取消（终态）
    Skipped,    // 入边全部被门控拦截，永不执行（终态）
}
// 保留但 v1 不产生：WaitingHuman（人工介入 v1.1）

/// run 状态
pub enum RunStatus {
    Running,
    Paused,
    Completed,  // 终态：静默结束且未失败
    Failed,     // 终态：冷峻失败（任一 Crashed/TimedOut/框架错误）
    Cancelled,  // 终态：用户取消
}

/// 节点执行错误（进入 InstanceRecord.error）
// NodeError.code 取值域（BusinessError.code）：NODE_RETURN_NOT_DICT / NODE_RETURN_NOT_JSON / BIZ_*（业务自定义）。
// 框架错误用 Internal/Config；Harness 配置失败用 Harness{kind: ConfigLoad}，NodeError::Config 仅用于非 Harness 资产加载。
pub enum NodeError {
    BusinessError { code: String, message: String },        // 节点主动抛出
    PythonException { message: String, traceback: String }, // Python 未捕获异常
    Timeout { elapsed_ms: u64 },                            // 实例级超时
    Cancelled,                                              // 协作取消
    Harness { kind: HarnessErrorKind, detail: Value },      // Agent Harness 错误
    Config { message: String },                             // 配置/资产加载失败
    Internal { message: String },                           // 框架不变量违反（fail-fast）
}

/// Harness 错误分类（映射见 05 分册 §5.7）
pub enum HarnessErrorKind {
    ConfigLoad,
    UnknownTool,
    MaxIterations,
    LlmError,
    LlmTimeout,
    ToolError,          // 仅喂回 LLM，不终止
    MemoryDegraded,     // 降级告警，不终止
}

/// 流式事件（节点 ctx.emit 产生；只进 trace，不参与数据通道）
pub enum StreamingEvent {
    TokenDelta { text: String },
    ReasoningDelta { text: String },
    ToolCallStart { call_id: String, tool_name: String, args_summary: Value },
    ToolCallEnd { call_id: String, tool_name: String, ok: bool, result_summary: Value },
    Progress { percent: u8, message: String },
}
```

```rust
/// 对外 trace 事件（06 分册持久化；不可丢/可丢见 00 §0.6 I6）
pub enum TraceEvent {
    RunStarted { run_id: RunId, graph_hash: GraphHash, user_id: String, at: DateTime<Utc> },
    Transition { record: TransitionRecord },
    Streaming { run_id: RunId, instance_id: InstanceId, event: StreamingEvent },
    GateResult { record: GateResultRecord },
    NodeTimedOut { run_id: RunId, instance_id: InstanceId, elapsed_ms: u64 },
    NodeAbandoned { run_id: RunId, instance_id: InstanceId, at: DateTime<Utc> },   // warning
    RunFinished { run_id: RunId, status: RunStatus, output_summary: Option<Value>,
                  error: Option<TraceError>, metrics: RunMetrics, at: DateTime<Utc> },
}

pub struct TraceError { pub code: String, pub message: String }
pub struct RunMetrics { pub streaming_dropped: u64, pub abandoned_tasks: u64, pub trace_backpressure: u64 }
```

**不可丢**：`RunStarted` / `Transition` / `GateResult` / `NodeTimedOut` / `NodeAbandoned` / `RunFinished`；**可丢**：`Streaming`（`try_send` + `streaming_dropped` 计数）。

## 0.4 错误码总表

错误码是**对外契约**：CLI 输出、trace、测试断言都依赖它。格式 `域_类别[_细节]`。

### DSL 域（图加载期；Loader 返回，不产生 run）

| 错误码 | 触发条件 | 规格来源 |
|---|---|---|
| `DSL_PARSE_ERROR` | 非法 JSON / 类型不符 | 02 §2.4 |
| `DSL_MISSING_FIELD` | 必填字段缺失 | 02 §2.4 |
| `DSL_DUPLICATE_NODE_ID` | 节点 ID 重复 | 02 §2.4 |
| `DSL_INVALID_ENTRY` | `entry_points` 指向不存在的节点 | 02 §2.4 |
| `DSL_INVALID_EDGE_REF` | 边引用不存在的节点 | 02 §2.4 |
| `DSL_INVALID_PORT` | `to_input_port` 未在目标节点声明 | 02 §2.4 |
| `DSL_DUPLICATE_EDGE` | 同 `(from, to_node)` 重复 | 02 §2.4 |
| `DSL_DUPLICATE_PORT_SOURCE` | 同一 `(to_node, to_input_port)` 有多条入边 | 02 §2.4 |
| `DSL_UNCONNECTED_INPUT` | 非 entry 节点 required input 无来源 | 02 §2.4 |
| `DSL_SUBGRAPH_INVALID` | 子图无 End / 多 End / mapping 非法 | 02 §2.4 |
| `DSL_CYCLE_DETECTED` | 无门控的纯数据环 | 02 §2.4 |
| `DSL_SYMBOL_NOT_FOUND` | gate/python 节点符号 import 失败 | 02 §2.5 |
| `DSL_SIGNATURE_MISMATCH` | 符号签名不符 | 02 §2.5 |
| `DSL_SYMBOL_CONFLICT` | 同名符号不同实现 | 02 §2.5 |
| `DSL_AGENT_NOT_FOUND` | `agent_id` 资产缺失 | 02 §2.5 |
| `DSL_UNSUPPORTED_NODE_TYPE` | 图中出现未知/保留的节点 `type` 字符串（v1 支持 start/end/python_node/agent_call/subgraph 五种；`subgraph` 运行期另报 `NODE_TYPE_UNSUPPORTED`） | 02 §2.6 |
| `DSL_UNSUPPORTED_FIELD` | 出现 v1 不支持/保留的字段（`from_output_port`、`on_error` 等） | 02 §2.6 |

> v1.1 的 `DSL_GATE_CONFLICT` / `DSL_GATE_SIGNATURE_MISMATCH` / `DSL_NODE_SIGNATURE_MISMATCH` 合并为 `DSL_SYMBOL_CONFLICT` / `DSL_SIGNATURE_MISMATCH`（细节在 message 中区分）。

### 运行期域

| 错误码 | 触发条件 | 影响 |
|---|---|---|
| `RUN_ILLEGAL_TRANSITION` | 状态机非法迁移 | run Failed（框架 bug，fail-fast） |
| `RUN_DELIVERY_TO_TERMINAL` | 投递到终态实例（非自环） | run Failed |
| `RUN_DEADLOCK` | 静默且存在永不就绪实例（超过 `deadlock_grace_ms`） | run Failed |
| `RUN_CANCELLED` | 用户取消 | run Cancelled |
| `RUN_ENTRY_INVALID` | entry_points 为空/不存在，或 entry_inputs 含多余节点或端口 | 启动失败（不产生 run） |
| `RUN_ENTRY_INPUT_MISSING` | entry 节点的 required 端口未被 entry_inputs 覆盖 | 启动失败（不产生 run） |
| `RUN_TOO_MANY` | 并发 run 超过 `max_concurrent_runs`（默认 32） | 启动失败 |
| `RUN_PYTHON_INIT` | 解释器初始化/导入失败 | run Failed |
| `NODE_TIMEOUT` | 实例超时 | 实例 TimedOut → run Failed（冷峻） |
| `NODE_ABANDONED` | 超时后任务仍未结束（记账告警，非错误码） | trace warning |
| `NODE_TYPE_UNSUPPORTED` | 运行到 v1 不支持的节点类型 | run Failed |
| `NODE_PYTHON_EXCEPTION` | Python 节点抛未捕获异常 | 实例 Crashed（`PythonException`） |
| `NODE_BUSINESS_ERROR` | 节点主动抛业务错误 | 实例 Crashed（`BusinessError`） |
| `NODE_INTERNAL` | 框架不变量违反 / handler panic | 实例 Crashed（`Internal`） |
| `NODE_CONFIG_ERROR` | 非 Harness 资产加载失败 | 实例 Crashed（`Config`） |

### Harness 域

| 错误码 | 触发条件 | 映射 |
|---|---|---|
| `HARNESS_CONFIG_LOAD` | AgentConfig/prompt 文件缺失或非法 | Crashed |
| `HARNESS_UNKNOWN_TOOL` | LLM 调用了未注册工具 | Crashed |
| `HARNESS_MAX_ITERATIONS` | 超过 `max_iterations` | Crashed（携带当前上下文摘要） |
| `HARNESS_LLM_ERROR` | provider 错误重试耗尽 | Crashed |
| `HARNESS_LLM_TIMEOUT` | 单次 LLM 调用超时且重试耗尽 | Crashed |
| `HARNESS_CONTEXT_OVERFLOW` | 预算裁剪后仍溢出 | Crashed（v1 不静默截断用户输入） |
| `HARNESS_MEMORY_DEGRADED` | 记忆检索/写入失败 | warning，继续 |
| `TOOL_ERROR` | 工具执行失败 | 喂回 LLM，继续循环 |

**CLI 命名空间（非领域码）**：`STORAGE_ERROR` / `STORE_SCHEMA_TOO_NEW` / `CLI_USAGE` 仅出现在 CLI 退出码与 stderr，**不写入** `runs.error_code`（06 §6.10.5）。

## 0.6 不变式（Violation = 框架 bug，debug 构建 `assert!`，release 转 `RUN_ILLEGAL_TRANSITION` 或 `Internal`）

| # | 不变式 | 违反时 |
|---|---|---|
| I1 | **实例单次执行**：同一 `InstanceId` 的 `run()` 至多调用一次；自环/重试产生新 `Attempt` | Internal |
| I2 | **状态单调**：只允许 01 §1.3 迁移矩阵中的迁移 | RUN_ILLEGAL_TRANSITION |
| I3 | **buffer 先于执行**：进入 Running 前，`trigger=all` 的全部 required 端口已在 buffer；`trigger=any` 至少一个 required 端口已到（其余为 `null`） | Internal |
| I4 | **每边至多一次投递**：单次 publish 中，每条边至多产生一个 Delivery | Internal |
| I5 | **run 终态唯一**：`RunFinished` 恰好发一次，且 status 为终态 | Internal（事件去重） |
| I6 | **trace 因果完整**：`RunStarted` / `Transition` / `GateResult` / `NodeTimedOut` / `NodeAbandoned` / `RunFinished` 不可丢（见 §0.3 TraceEvent）；`Streaming` 可丢但有计数。**存储不可写 = fail-stop**：run 标 Failed，CLI 退出码 4（06 §6.4.5） | 告警 + 指标；fail-stop |
| I7 | **门控纯函数**：gate 只读 `output + GateContext`，不写全局、不发事件、不改数据；异常/panic 视为不通过 | 拦截 + warning |
| I8 | **事件循环线程不执行 Python**：任何同步 Python 调用必须离开事件循环线程 | Internal |
| I9 | **冷峻失败**：任一实例 `Crashed` / `TimedOut` → run 立即 `Failed`，其余非终态实例转 `Cancelled` | — |

## 0.7 术语与消歧（v1.1 歧义在此统一）

| v1.1 说法 | v1.2 统一为 |
|---|---|
| gate 的 `ctx: &RunContext`（6.5）vs `NodeContext`（5.2） | **GateContext**（只读：`user_id`/`get_var`/`params`），见 04 §4.6 |
| `EdgeRef { edge: &'static CompiledEdge }` | **`EdgeRef(EdgeIndex)`**，边数据从 `CompiledGraph.edges[..]` 取，见 01 §1.2 |
| `Delivery` 无目标实例字段 | **必填 `to_instance`**（旧称 `to_instance_id` 作废），见 01 §1.4 |
| `run.buffers.write(...)` | `RunState::buffer_write(instance_id, port, value)`，见 03 §3.4 |
| "实例只跑一次" vs HumanInput 重跑 | v1 无人工介入；**保持 I1 严格成立**；恢复语义留 v1.1 |
| "全 Completed" vs "全终态" | **无活跃实例（Pending/Ready/Running）** 即静默；冷峻失败优先，见 03 §3.9 |
| 超时 30s（4.3）vs LLM 60s（3.4） | 实例 180s / LLM 60s / 工具 30s，见 §0.5 |
| `run()` panic | 捕获为 `NodeError::Internal` → Crashed → run Failed（不 unwind 事件循环） |
| optional 端口未到 | **全部声明端口都出现在 `inputs` 中，未到值为 `null`**（Python 侧 `None`）；`trigger=any` 的未到 required 端口同样为 `null` |
